# satellite-orbit-simulation
Interactive 3D-style satellite orbit simulation based on Newtonian orbital mechanics.
## Development Process

This project was developed as an educational exploration of satellite orbital mechanics.

AI-assisted tools were used for initial prototyping, code generation, and interface development. The simulation is being studied, tested, and progressively refined to strengthen my understanding of orbital mechanics and computational modeling.
